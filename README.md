# صندوق المقبرة والشادر — PWA

هذه النسخة مصممة لتعمل كتطبيق ويب تقدمي (PWA) على الهاتف ويمكن نشرها مباشرة على GitHub Pages.

## النشر
1. ارفع جميع الملفات والمجلدات إلى المستودع.
2. من **Settings → Pages** اختر النشر من الفرع الذي يحتوي على الملفات.
3. افتح رابط GitHub Pages من هاتف Android عبر Chrome.
4. اختر **تثبيت التطبيق / Add to Home screen**.

## ملاحظات
- البيانات محلية على الجهاز باستخدام LocalStorage.
- النسخ الاحتياطي والاستعادة بصيغة JSON موجودان داخل البرنامج.
- تصدير Excel يعتمد على مكتبة SheetJS المحمّلة من CDN عند أول تشغيل متصل؛ بعد فتح البرنامج مرة عبر الإنترنت يقوم Service Worker بتخزين موارد التشغيل المتاحة.
- لا تغيّر أسماء `index.html` أو `manifest.webmanifest` أو `sw.js` أو مجلد `icons`.
